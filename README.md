# ZiggyDraw

**A lightweight, native Windows screen annotation and whiteboard tool.**

ZiggyDraw is a free screen annotation and whiteboard application for Windows. It focuses on smooth vector inking, lightweight performance, and a simple, efficient user experience.

## Features

- Draw and annotate directly on your screen, over any application.
- Soft pen, hard pen, and highlighter tools, with simulated stroke variation for natural-looking handwriting even with a mouse.
- Smooth, responsive vector inking with real-time stroke smoothing.
- Support for mouse, touchscreen, and graphics tablet input. Active pens are not currently supported.
- Built-in whiteboard for freehand drawing and presentations.
- Laser pointer and geometric shape drawing tools.
- Hand-drawn shape recognition that converts supported sketches into regular geometric shapes after a brief pause.
- Export drawings as images, SVG, Excalidraw, or tldraw formats, with options to prioritize editability or visual fidelity.
- Built with Zig and native Windows APIs, with an executable size of approximately 1 MB.
- Compatible with Windows 7 SP1 and later. Some features may have limited functionality on older Windows versions.
- Free forever, with no ads, no telemetry, and no personal data collection.

## Made for Windows

ZiggyDraw is developed specifically for Windows using native graphics technologies. It aims to provide a lightweight, responsive, and straightforward screen annotation experience. 

## Free to Use

ZiggyDraw is freeware and completely free to use. If you find it useful, you can optionally support its development with a donation. Donations are entirely voluntary. 

## Development Status

ZiggyDraw is currently in early development. Features may change, and bugs or compatibility issues may still exist. Bug reports, suggestions, and feedback are welcome.
